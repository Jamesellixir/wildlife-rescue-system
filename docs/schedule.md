# Development schedule

All dates are in November 2026, Asia/Colombo time. Commits record work completed on the actual date. Work begins when the student requests the next part.

| Date | Commit title | Work completed |
|---|---|---|

| 10 Nov | `Set up the Java project and test tools` | Configure Java, Maven, dependencies, test runner and build checks. |

The system is due to be complete on 23 November inclusive. The report follows on 24 to 28 November, with final review and viva practice from 29 November.

Each feature includes relevant tests. Missed milestones are rescheduled without changing commit timestamps. Extra commits are permitted for genuine repairs.
